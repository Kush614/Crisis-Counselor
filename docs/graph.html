How the loop works

Score → diagnose → rewrite → re-score, on repeat

01
Score
Cekura runs 8 personas (passive ideation, panic, grief, returning caller…) against the live agent and grades each metric.
02
Diagnose
The loop ranks the worst metrics — here: reassurance, continuity-with-memory, empathy-first.
03
Rewrite
An optimizer LLM rewrites the system prompt targeting exactly those failures, grounded in real counselor transcripts.
04
Re-score
New prompt is hot-pushed to the deployed agent (no redeploy) and re-scored. Kept only if the composite went up.
